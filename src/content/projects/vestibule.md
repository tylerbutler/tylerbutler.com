Add real OAuth sign-in flows to Gleam demos and prototypes through a strategy-based API for multiple providers. Vestibule is pre-1.0 and distributed through Git rather than Hex. The project uses Trellis for releases.

> [!WARNING]
> Vestibule has not been security audited. Do not use it in production or treat it as secure.
