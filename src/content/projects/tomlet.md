Read and edit TOML configuration without losing comments, key order, or surrounding formatting. Tomlet parses TOML 1.1 into an opaque document and provides typed accessors and edits. Unedited documents round-trip to their original text.

Available under either the MIT or Apache-2.0 licence. The project uses Trellis for releases.
